# ADR-002: ArchUnit을 이용한 아키텍처 규칙 강제

## 상태

승인됨 (2026-04-04)

## 맥락

레이어드 아키텍처 규칙(ADR-001)이 코드 리뷰에만 의존하면
AI 에이전트나 개발자가 실수로 위반할 수 있다.
규칙 위반을 빌드 시점에 자동으로 감지할 수 있는 메커니즘이 필요하다.

## 결정

ArchUnit을 도입하여 아키텍처 규칙을 JUnit 테스트로 강제한다.

### 검증 규칙
1. 도메인 내부 레이어 의존성 방향
2. 도메인 간 의존성 제한
3. 네이밍 컨벤션 준수

## 이유

1. **자동화**: 빌드 시점에 검증되므로 사람의 실수를 방지
2. **하네스 엔지니어링**: 에이전트가 생성한 코드의 구조적 정합성을 기계적으로 보장
3. **비용 효율**: 코드 리뷰에서 구조적 문제를 논의할 필요가 없어짐
4. **문서 역할**: 테스트 코드 자체가 아키텍처 규칙의 실행 가능한 문서

## 결과

- `./gradlew test` 실행 시 ArchUnit 테스트도 함께 실행
- 규칙 위반 시 빌드 실패 → 커밋/푸시 차단
- 새로운 아키텍처 규칙은 ArchUnit 테스트로 추가
